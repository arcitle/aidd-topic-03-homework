См. ветки codex и cursor

Для выполнения поставленной задачи были выбраны агенты:
 - codex (модель GPT-6-Luna с Reasoning: Medium)
 - cursor (модель Auto с Reasoning auto)

Какие задачи ставились агенту?
Агенту ставились задачи по чтению, изменению и написанию кода.
Какие основные промпты были использованы?
Был использован текст задания с указаниями, куда писать (.md файлы), а также указаниями на использование docker и виртуальной среды для большей переносимости.
Какие ошибки и проблемы возникали при работе с агентом?
Codex изначально попытался чрезмерно упростить приложение, заменив postgres на sqlite, эти изменения были отклонены.
Какие корректировки вносились в работу агента?
Иногда агент работал недобросовестно, например пытаясь подсматривать в ветку другого агента, уже выполнившего задание. В этом случае создавалась новая сессия с запретом подобных действий.
Как проверялись результаты работы агента?
Документация и результат работы агента читался, а приложение запускалось и тестировалось.
Сколько времени и итераций потребовалось для выполнения заданий каждым агентом?
На выполнение задания ушло около 3.5 часов, не считая изначальной настройки агентов. На каждое задание хватало не более 3-4 итераций.


Каждый агент имеет свою ветку приложения.
Cursor написал наиболее подробные описания функционала и функциональные требования и также лучше написал тесты, но постоянно требовал уточнений и дополнительных итераций для исправления кода.
Codex лучше писал код, с первого раза понимая требования.
Оба агента работали вполне автономно. Но cursor имеет меньшие лимиты, по сравнению с Codex.
Также cursor чаще выполнял команды, предварительно склеивая множество команд в одну при помощи `&&`.

Сравнительная таблица:

| Параметр      | Codex | Cursor |
| ------------- | ----- | ------ |
| Качество      | +     | -      |
| Автономность  | +     | +      |
| Подробность   | -     | +      |
| Эффективность | +     | +      |
| Лимиты        | +     | -      |


В целом можно заключить, что codex лучше справляется с написанием нового кода, в то время как cursor лучше подходит для написания документации и тестов.
